## 问题列表

### 1) 导入摘要“进入工作台”看起来无响应（实际为必填未满足）

- 状态：已修复（2026-04-30）
- 现象：
  - 用户上传 YAML 后，点击“进入工作台”无反应。
- 触发条件：
  - `项目名称` 或 `项目编号` 为空时，按钮被禁用。
- 当前结论：
  - 这是当前交互规则，不是后端故障。
  - 已确认该页的进入条件为：
    - `projectName.trim().length > 0`
    - `projectCode.trim().length > 0`
    - `yamlText.trim().length > 0`
- 建议处理：
  - 在按钮附近增加显式必填提示（例如“请先填写项目名称与项目编号”）。
  - 为禁用按钮补充 tooltip 或辅助文案，避免误判为接口卡住。
- 修复说明：
  - “保存并查看总览”按钮在禁用时已增加显式灰化、禁用光标和 tooltip。
  - 表单区已增加缺失必填项提示文案（按实际缺失字段动态展示）。

### 2) “进入工作台”与后端保存串行等待导致体感卡顿（已修复）

- 状态：已修复（2026-04-30）
- 现象：
  - 点击后需要等待 `import_yaml + save_config` 完成，若后端慢则像没点。
- 当前结论：
  - 前端已改为“先进入工作台，再后台异步保存”，降低阻塞感。
- 建议处理：
  - 后续补“后台保存中/失败”状态提示，提升可观测性。

### 3) 导入后主路径应先进入只读总览，且回填必须依赖权威 form_state（已修复）

- 状态：已修复（2026-04-30）
- 现象：
  - 导入后直接跳转工作台，不符合“版本化保存后先总览”的业务预期。
  - 出现 YAML 文本有值但工作台输入框未回填。
- 根因：
  - 之前采用“先跳工作台再后台保存”的临时策略。
  - 工作台回填读取的是内存态 `importResult.form_state`，当导入请求失败或未返回时会退化为空。
- 修复：
  - 导入摘要主动作改为“保存并查看总览”。
  - 严格串行：`import_yaml` 成功且返回非空 `form_state` -> `save_config` -> `load_config` -> 跳转总览。
  - 失败时停留导入摘要并显示错误提示。
  - 工作台回填优先使用 `load_config.form_state`（持久化权威数据）。

### 4) 未运行状态下“查看结果”按钮禁用样式与空态提示不够明确（待优化）

- 状态：已修复（2026-04-30）
- 现象：
  - 当前导入后未运行版本中，“查看结果”不可点击，但缺少更明确的视觉禁用态与“暂无结果”提示。
- 当前结论：
  - 行为上已禁止未运行版本查看结果，符合业务逻辑。
  - 交互提示仍可增强，减少用户疑惑。
- 建议处理：
  - 按钮增加显式禁用样式（灰色、禁用光标、弱化阴影）。
  - 按钮文案或邻近提示补“暂无结果（请先运行）”。
- 修复说明：
  - 总览页“查看结果”在未运行状态下已显式灰化并显示禁用光标，按钮附带 tooltip。
  - 只读提示区已补充“暂无结果（请先运行）”空态提示。

### 5) 导入后“新建初始化”禁用但视觉不够明确（待优化）

- 状态：已修复（2026-04-30）
- 现象：
  - 导入配置后，“新建初始化”已禁用不可点击，但视觉上未明显变灰，用户不易一眼识别为禁用态。
- 当前结论：
  - 交互行为正确（已禁用），但可视反馈不足。
- 建议处理：
  - 与其他禁用态统一：灰底、灰字、禁用光标、降低阴影/对比度。
- 修复说明：
  - 顶部导航“新建初始化”禁用态已统一为灰底灰字、禁用光标、弱化阴影。

### 6) 标定页 JSON 联动高亮在同名字段下错位（FSB/EB 冲突）

- 状态：已修复（2026-04-30）
- 现象：
  - 标定区 `service_brake` 与 `emergency_brake` 存在同名字段（如 `k_for_code`、`BCP0`）时，右侧 JSON 定位与高亮可能落到错误分支。
- 触发条件：
  - 编辑标定卡片字段后，`lastChangedPath` 仅按字段名回退匹配，未限定分支和点位索引。
- 修复说明：
  - 标定点路径已改为带索引路径（`points[0]` / `points[1]`）。
  - JSON 高亮已增加按分支与索引的定向定位逻辑（含 `BCP0` 定向定位），避免同名字段串位。

### 7) 结果页标定区信息密度与布局可读性优化

- 状态：已修复（2026-04-30）
- 现象：
  - 标定参数卡片“来源”文案占据较大空间，卡片信息密度偏低；
  - 分段公式与曲线图分离，不利于一一对应阅读。
- 修复说明：
  - 控制器开发参数区卡片已移除“来源”行，提升有效信息密度；
  - 右侧曲线区已放大，且 `service_brake` / `emergency_brake` 分段公式分别移动到对应曲线下方；
  - 标定点展示改为两点坐标语义卡片（按模式点位展示）。

### 8) 停放校核未开启时结果区展示策略

- 状态：已修复（2026-04-30）

- 修复说明：
